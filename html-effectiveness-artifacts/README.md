# The Unreasonable Effectiveness of HTML - Artifacts Collection

이 프로젝트는 [The unreasonable effectiveness of HTML](https://thariqs.github.io/html-effectiveness/) 웹사이트에 소개된 20개의 HTML 아티팩트를 수집하고 문서화한 것입니다.

## 구조

각 아티팩트는 카테고리별 폴더로 분류되어 있으며, 각 폴더 내에는 해당 아티팩트의 **원본 HTML 파일**과 **설명 및 소스 코드가 포함된 README.md** 파일이 들어 있습니다.

### 카테고리 목록

1. **01-exploration-planning**: 탐색 및 계획 (3개)
2. **02-code-review-understanding**: 코드 리뷰 및 이해 (3개)
3. **03-design**: 디자인 (2개)
4. **04-prototyping**: 프로토타이핑 (2개)
5. **05-illustrations-diagrams**: 일러스트레이션 및 다이어그램 (2개)
6. **06-decks**: 슬라이드 덱 (1개)
7. **07-research-learning**: 연구 및 학습 (2개)
8. **08-reports**: 보고서 (2개)
9. **09-custom-editors**: 커스텀 편집기 인터페이스 (3개)

## 사용 방법

각 폴더로 이동하여 `README.md`를 통해 설명을 확인하거나, `.html` 파일을 브라우저에서 직접 열어 아티팩트의 동작을 확인할 수 있습니다.
